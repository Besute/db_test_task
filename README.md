## Setup
1) Чтобы воспользоваться консольным приложением, используйте Poetry

2) После установки Poetry в качестве окружения Python пропишите в консоли
"Poetry lock", затем "Poetry sync"

Это установит все зависимости для проекта

3) После этого откройте файл .env и настройте окружение для PostgreSQL под себя. Шаблон можно посмотреть в .env.exmp . Это нужно для создания БД и работы с созданными там таблицами

## Usage
После пункта **Setup** вы сможете использовать консольное приложение

### Commands

python -m getinfo --product "НАЗВАНИЕ" [--version НАЗВАНИЕ]

1) Флаг --product обязательный: сюда Вы должны передать название продукта

2) Флаг --version необязательный (по умолчанию принимает значение None): сюда Вы должны передать версию продукта

Только после того, как --version перестанет быть None (то есть вы передадите туда любой аргумент) программа начнёт искать инфомрацию об уязвимостях

**Примечание 1: задание было выполнено на Ubuntu**

**Примечание 2: в условии для 2 части задания (по выводу уязвимостей) не было сказано о том, что делать, если введённая пользователем версия или продукт не будет(ут) найдена(ы) в versions.json. Моя реализация предполагает, что в versions.json может не содержаться введённая пользователем версия или название продукта (то есть программа отработает штатно)**
